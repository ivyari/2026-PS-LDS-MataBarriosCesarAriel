Demo de sesiones con JWT · CECyT 9

Aquí la sesión NO va en una cookie: va dentro de un token que guarda la página y manda en el encabezado Authorization: Bearer <token>. Abre F12 → Network para verlo. · ← Volver a la demo con cookie

1 · Iniciar sesión con JWT

El servidor no crea sesión ni cookie: responde con el token y esta página lo guarda en una variable de JavaScript (en memoria). Si recargas la página, el token se pierde.

3 · El token

Tiene tres partes separadas por puntos: encabezado · payload (los datos) · firma. Las dos primeras solo están en Base64URL: cualquiera las puede leer. Lo que nadie puede hacer sin el secreto del servidor es cambiarlas, porque la firma ya no coincidiría.
